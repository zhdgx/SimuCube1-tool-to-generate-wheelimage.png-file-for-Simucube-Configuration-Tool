1. Usage: Simply extract the archive to the root directory of your Simucube software and overwrite the original  wheels  folder.
​
2. The tool is easy to use. It automatically backs up all your previously used wheel images to prevent data loss. You can retrieve them from the  wheel_backup  folder.
​
3. Replacement images must be 400×400 resolution PNG files with transparency. I have included many pre-made images in the archive for immediate use; just select and apply them.
​
4. If your antivirus flags the program, add it to your trusted list.
​
5. This update adds image processing features, allowing basic image adjustments to meet usage requirements.
